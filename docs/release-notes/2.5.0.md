> **Beta:** Saga is ready for everyday use, but still young – keep regular backups; some features are explicitly
> experimental (above all calls through Gjallarhorn).

The Saga apps 2.5 belong to [Saga server 2.5](https://github.com/yggdrasil-sh/saga/releases). **The new features need
Saga server 2.5**, and the server admin can still switch some of them off (modern chats, calls through the node); with
older servers and contacts on older versions everything works as before. Deutsch: see below.

## Highlights

- **Calls through your Saga address behind any proxy** (Gjallarhorn, experimental): iPhone/iPad, Android and the Mac
  app tunnel their calls over a WebSocket to the normal Saga address – also behind Nginx Proxy Manager with
  "Websockets Support". Echo cancellation, jitter buffer and end-to-end encryption stay the same.
- **Calls that grow** (iOS, Android): add people to a running call, turn a 1:1 into a conference without a new
  connection, "Not in the call" with "Ring again". Calls through the node carry a small "Experimental" mark.
- **The Mac app is now the desktop shell:** your server's web interface in a native window, with desktop widgets,
  the share menu, notifications, menu bar, Spotlight and self-updates. Sign-in, widgets, the share menu and
  notifications carry over without signing in again.
- **Modern chats on iOS, Android and Linux:** groups with picture, description and admins, pinned messages, mute for a
  set time, mentions, formatting, blocking and reporting, contacts – each feature only when the server offers it.
- **Editing together:** iOS and Android merge changes block by block instead of showing a conflict dialog; the Linux
  app edits live together with the web editor (when the admin turns on live co-editing).
- **Pages and databases:** sub-pages as a list or gallery, Saga seals as page icons, the cover gallery, the template
  gallery, a graph of your pages like in Obsidian, widgets and charts in pages; on Linux also the timeline view.
- **BookOrbit "Reading"** widget and a reading card under Today (iOS, Android).
- **Error reports and "Send diagnostics"** in all apps, plus an update notice under Info.
- **Large files in chat** in the new block format, a picture gallery with zoom, forwarding from the message menu.
- **Android:** several design rounds (navigation, editor, database views, chats and calls, tablets) and notification
  texts in the app language.
- **Security:** hardening after the second penetration test (Android, iOS/Mac, Linux).

## Upgrading from 2.4

- **Android:** install `Saga-2.5.0.apk` (allow installation from unknown sources).
- **Mac:** install `Saga-2.5.0-macOS.dmg` once by hand – self-updates (Sparkle) start with 2.5. The app becomes the
  desktop shell; a one-time note explains what is new, and encrypted chats ask you to confirm the Mac once more.
- **Linux:** update the RPM, or install the new Flatpak (`flatpak install --user saga-2.5.0-x86_64.flatpak`).
- **iPhone/iPad:** there is no App Store version – build it yourself or get it from your admin (e.g. via MDM).
- The server needs [Saga 2.5](https://github.com/yggdrasil-sh/saga/releases) for the new features; for calls through
  the node the proxy must pass WebSockets through (see the server's upgrade guide).

## Known limitations

- **Gjallarhorn is experimental**, tested with up to 4 people or devices per call; please report problems via
  "Send diagnostics".
- On Linux the app rings, the call itself runs in the browser.
- The native SwiftUI part of the Mac app is frozen; the Mac app shows the web interface.
- iPhone/iPad: no App Store version yet.

## Deutsch

> **Beta:** Saga ist im Alltag nutzbar, aber noch jung – mach regelmäßig Backups; einige Funktionen (vor allem Anrufe
> über Gjallarhorn) sind ausdrücklich experimentell.

Die Saga-Apps 2.5 gehören zu [Saga-Server 2.5](https://github.com/yggdrasil-sh/saga/releases). **Die neuen Funktionen
brauchen Saga-Server 2.5**, der Admin kann einige davon dort abschalten (moderne Chats, Anrufe über den Knoten); mit
älteren Servern und Gegenstellen bleibt alles wie bisher.

### Höhepunkte

- **Anrufe über die Saga-Adresse hinter jedem Proxy** (Gjallarhorn, experimentell): iPhone/iPad, Android und die
  Mac-App tunneln ihre Anrufe per WebSocket über die normale Saga-Adresse – auch hinter Nginx Proxy Manager mit
  „Websockets Support“. Echo-Unterdrückung, Jitter-Puffer und Ende-zu-Ende-Verschlüsselung bleiben gleich.
- **Anrufe, die mitwachsen** (iOS, Android): Personen in den laufenden Anruf holen, aus einem 1:1 ohne Neuaufbau eine
  Konferenz machen, „Nicht dabei“ mit „Erneut klingeln“. Anrufe über den Knoten tragen eine kleine Marke
  „Experimentell“.
- **Die Mac-App ist jetzt die Desktop-Hülle:** die Web-Oberfläche deines Servers im eigenen Fenster, mit Widgets auf
  dem Schreibtisch, Teilen-Menü, Mitteilungen, Menüleiste, Spotlight und Selbst-Update. Anmeldung, Widgets, Teilen-Menü
  und Mitteilungen gehen ohne Neuanmeldung über.
- **Moderne Chats auf iOS, Android und Linux:** Gruppen mit Bild, Beschreibung und Admins, angeheftete Nachrichten,
  stummschalten mit Dauer, Erwähnungen, Formatierung, sperren und melden, Kontakte – jede Funktion nur, wenn der Server
  sie anbietet.
- **Gemeinsam bearbeiten:** iOS und Android führen Änderungen blockweise zusammen statt eines Konfliktdialogs; die
  Linux-App schreibt live mit dem Web-Editor mit (wenn der Admin „Gleichzeitig bearbeiten live“ einschaltet).
- **Seiten und Datenbanken:** Unterseiten als Liste oder Galerie, Saga-Siegel als Seitensymbole, Titelbild- und
  Vorlagengalerie, Graph der Seiten wie in Obsidian, Widgets und Diagramme in Seiten; unter Linux auch die Zeitleiste.
- **BookOrbit „Lesen“** als Widget und Karte unter „Heute“ (iOS, Android).
- **Fehlerberichte und „Diagnose senden“** in allen Apps, dazu ein Update-Hinweis unter „Info“.
- **Große Dateien im Chat** im neuen Blockformat, Bildergalerie mit Zoom, Weiterleiten im Nachrichtenmenü.
- **Android:** mehrere Design-Runden (Navigation, Editor, Datenbank-Ansichten, Chats & Anrufe, Tablet) und
  Mitteilungstexte in der App-Sprache.
- **Sicherheit:** Härtung nach dem zweiten Pentest (Android, iOS/Mac, Linux).

### Upgrade von 2.4

- **Android:** `Saga-2.5.0.apk` installieren (Installation aus unbekannten Quellen erlauben).
- **Mac:** `Saga-2.5.0-macOS.dmg` einmal von Hand installieren – das Selbst-Update (Sparkle) gibt es ab 2.5. Die App wird
  zur Desktop-Hülle; ein Hinweis erklärt einmal, was neu ist, verschlüsselte Chats bestätigen den Mac einmal neu.
- **Linux:** RPM aktualisieren bzw. das neue Flatpak installieren (`flatpak install --user saga-2.5.0-x86_64.flatpak`).
- **iPhone/iPad:** keine Version im App Store – selbst bauen oder vom Betreiber bekommen (z. B. per MDM).
- Für das Neue braucht der Server [Saga 2.5](https://github.com/yggdrasil-sh/saga/releases); für Anrufe über den Knoten
  muss der Proxy WebSockets durchreichen (siehe Upgrade-Anleitung des Servers).

### Bekannte Grenzen

- **Gjallarhorn ist experimentell**, getestet mit bis zu 4 Personen bzw. Geräten je Anruf; Probleme bitte über
  „Diagnose senden“ melden.
- Unter Linux klingelt die App, das Gespräch selbst läuft im Browser.
- Der native SwiftUI-Teil der Mac-App ist eingefroren; die Mac-App zeigt die Web-Oberfläche.
- iPhone/iPad: noch keine Version im App Store.
